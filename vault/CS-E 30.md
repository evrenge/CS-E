# CS-E 30 — Assumptions

> [!quote] CS-E 30(a)
> "In order that the validity of the conditions assumed in the Engine certification may be assessed for any particular installation, prior to Engine certification, the details of the assumptions made must be submitted."

## Requirement

| Ref | Obligation | Strength |
|---|---|---|
| **(a)** | Submit the details of the assumptions made about the conditions the aircraft installation may impose on the engine, before engine certification. Include those assumptions in the engine instructions for installation required under CS-E 20(d). | Required |
| **(b)** | Where an engine system relies on components outside the engine type design, specify the interface conditions and reliability specifications for those components, on which the engine certification is based, in the engine instructions for installation — directly or by reference. | Required |

CS-E is written for an engine certified without a specific aircraft. The engine
is therefore certified against assumed installation conditions, and this
paragraph forces those assumptions into the open so an installer can check them
against the real aircraft.

## Compliance

- Statement of installation assumptions, submitted before engine certification [CS-E 30(a)].
- Engine instructions for installation carrying those assumptions [CS-E 30(a)], within the manuals required by [[CS-E 20|CS-E 20(d)]].
- Interface conditions and reliability specifications for components outside the engine type design, in the instructions for installation or referenced from them [CS-E 30(b)].

## Application to this engine

Sub-point (b) is load-bearing for a full-authority EECS. Where the control system
depends on aircraft-supplied resources — electrical power, air data, or recorded
rotorcraft OEI data — those are components outside the engine type design, so
their interface conditions and reliability specifications belong here.

The assumed aircraft certification specification code is identified under this
paragraph by way of [[CS-E 20|CS-E 20(b)]]. For a rotorcraft engine that code is CS-27 or
CS-29.

cites both CS 27.1093(b) and CS 29.1093(b), so CS-E itself does not settle it.]
