# CS-E 30 — Assumptions

> [!summary]
> CS-E certifies an engine without a specific aircraft, so certification rests
> on assumptions about what the installation will impose. This paragraph makes
> those assumptions explicit: they must be submitted before certification and
> carried in the instructions for installation, so an installer can check them
> against the real aircraft. Where the engine relies on components outside its
> type design, their interface conditions and reliability specifications must be
> specified too.

## Requirement

| Ref | Obligation | Strength |
|---|---|---|
| **(a)** | Submit the details of the assumptions made about the conditions the aircraft installation may impose on the engine, before engine certification. Include those assumptions in the engine instructions for installation required under CS-E 20(d). | Required |
| **(b)** | Where an engine system relies on components outside the engine type design, specify the interface conditions and reliability specifications for those components, on which the engine certification is based, in the engine instructions for installation — directly or by reference. | Required |

CS-E is written for an engine certified without a specific aircraft. The engine
is therefore certified against assumed installation conditions. This paragraph
requires those assumptions to be submitted, so that their validity can be
assessed for any particular installation [CS-E 30(a)].

## Compliance

- Statement of installation assumptions, submitted before engine certification [CS-E 30(a)].
- Engine instructions for installation carrying those assumptions [CS-E 30(a)], within the manuals required by [[CS-E 20|CS-E 20(d)]].
- Interface conditions and reliability specifications for components outside the engine type design, in the instructions for installation or referenced from them [CS-E 30(b)].

## Application to this engine

Sub-point (b) is load-bearing for a full-authority EECS. The control system may
depend on aircraft-supplied resources: electrical power, air data, or recorded
rotorcraft OEI data [AMC E 20(5)], [AMC E 20(6)]. Where it does, the components
that supply them are outside the engine type design. Their interface conditions
and reliability specifications then belong in the instructions for installation
[CS-E 30(b)].

The assumed aircraft certification specification code is identified under this
paragraph by way of [[CS-E 20|CS-E 20(b)]]. CS-E 30 does not name the code for a
rotorcraft engine.

[VERIFY: confirm whether the installation target is CS-27 or CS-29. CS-E 780
cites both CS 27.1093(b) and CS 29.1093(b) [CS-E 780(a)(2)], so CS-E itself does
not settle it.]

The two codes are not interchangeable. Their rotor drive system tests differ in
substance, and the engine data each one needs differs with them. See
[[CS 29.927]] and [[CS 27.927]].
