# CS-E 140 — Tests - Engine Configuration

> [!summary]
> This paragraph fixes what the engine must look like when it is tested. The
> configuration must be representative of the type design, automatic controls
> and protections must be running, and variable devices must be set to the type
> design. Accessory drives are unloaded for calibration and loaded for
> everything else, with one relief for the additional endurance test of
> CS-E 740(c)(3)(iii). Where a feature belongs to the aircraft rather than the
> engine, it must still be represented in the tests if engine performance
> depends on it.

## Requirement

| Ref | Obligation | Strength |
|---|---|---|
| **(a)** | Make the configuration of the engine, components or parts to be tested sufficiently representative of the type design for the purpose of the test. | Required |
| **(b)** | Have all automatic controls and protections in operation, unless it is accepted that this is not possible, or that they are not required because of the nature of the test. | Required |
| **(c)** | Set variable devices that are not intended to be adjusted during engine operation in accordance with the type design before each test, except where the particular test demands adjustments or a specific-test paragraph requires otherwise. | Required |
| **(c)** | Operate other variable devices in a manner consistent with both the type design and the operating instructions provided under CS-E 20(d), unless otherwise necessary for the purpose of the test. | Required |
| **(d)(1)** | Disconnect or off-load all equipment drives not essential to the satisfactory functioning of the engine during the Calibration Tests of CS-E 730. | Required |
| **(d)(1)** | Throughout all other tests, except as required by CS-E 140(d)(2), load those drives suitably, with the equipment listed in the constructor's declaration or with slave units of a suitable type. | Required |
| **(d)(2)** | When running the additional endurance test sequence required by CS-E 740(c)(3)(iii), the accessory drives and mounting attachments need not be loaded, if it can be substantiated that there is no significant effect on the durability of any accessory drive or engine component. | Relief |
| **(d)(2)** | In that case, add the equivalent engine output power extraction from the power turbine rotor assembly to the engine shaft output. | Required |
| **(e)** | Where certain features prescribed in CS-E 500 and CS-E 560 to CS-E 590 are incorporated as part of the aircraft installation rather than the engine type design, and engine performance is affected, represent those features satisfactorily throughout the engine tests. | Required |

The relief in (d)(2) is conditional and it is not free. It removes the loading
requirement only where the durability argument is substantiated. It then moves
the load rather than removing it: the equivalent power extraction must be added
to the engine shaft output, so the power turbine rotor assembly still does the
work [CS-E 140(d)(2)].

Sub-point (b) allows two distinct exceptions: operation is not possible, or it
is not required by the nature of the test. Both need acceptance rather than a
unilateral decision [CS-E 140(b)].

Sub-point (e) closes a gap created by the engine/aircraft split. A fuel, oil,
air or starting feature that the installer supplies is still part of what makes
the engine perform, so the tests must represent it [CS-E 140(e)].

## Compliance

- Test configuration statement for each certification test, showing representativeness against the type design [CS-E 140(a)].
- Record of which automatic controls and protections were in operation, with the accepted justification where any were not [CS-E 140(b)].
- Variable device settings recorded before each test, against the type design and the operating instructions of [[CS-E 20|CS-E 20(d)]] [CS-E 140(c)]. The post-test check on those settings is required by [[CS-E 150|CS-E 150(e)]].
- Accessory drive loading schedule: unloaded for the calibration test of [[CS-E 730]], loaded for all other tests, with the constructor's declaration of the equipment or the slave units used [CS-E 140(d)(1)].
- Durability substantiation and the equivalent power extraction added to shaft output, where the (d)(2) relief is taken for the [[CS-E 740|CS-E 740(c)(3)(iii)]] sequence [CS-E 140(d)(2)]. Accepted means: [[AMC E 140]].
- Identification of features under [[CS-E 500]] and [[CS-E 560]] to [[CS-E 590]] that are supplied by the aircraft installation, and the means used to represent them in the tests [CS-E 140(e)].

## Application to this engine

Sub-points (a), (b), (c), (d) and (e) apply. Sub-point (d)(1) names two
calibration paragraphs, CS-E 350 and CS-E 730; CS-E 350 is the piston
calibration test in Subpart C and does not apply, so the calibration test for
this engine is [[CS-E 730]].

Sub-point (d)(2) is directly relevant. The additional endurance test sequence of
[[CS-E 740|CS-E 740(c)(3)(iii)]] is the additional test for engines with
30-Second and 2-Minute OEI Power ratings [CS-E 740(c)(3)]. This engine declares
30-Second OEI, 2-Minute OEI and Continuous OEI Power ratings. The relief and its
power substitute therefore apply to this programme, and [[AMC E 140]] gives the
accepted means for the power addition.

Sub-point (b) carries weight for a full-authority EECS. The automatic controls
and protections that must be in operation are those of the EECS-FADEC. A test
run with a protection inhibited therefore needs the acceptance that (b)
requires. This connects to [[CS-E 50]].

## Not applicable

- **(d)(1)**, in part — the reference to the Calibration Tests of CS-E 350. That paragraph is the piston engine calibration test in Subpart C. For this engine the calibration test is [[CS-E 730]].
- **(f)** — combined engine and propeller tests under CS-E 180, and other tests prescribed in the Certification Specifications for Propellers. A turboshaft driving a rotorcraft transmission has no propeller, and propeller material is excluded from this vault by scope.
