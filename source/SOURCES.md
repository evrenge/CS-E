## Role of each file

- **CS-E Amendment 8** — the normative baseline. Current consolidated text of the
  CS-E book (CS-E Subparts A–F plus AMC). Every slide's requirement text is
  quoted from here.
- **Change Information, Amdt 8** — redline of Amendment 8 against Amendment 7.
  Drives the "changed at Amdt 8" tag on a slide.
- **Change Information, Amdt 7** — redline of Amendment 7 against Amendment 6.
  Drives the "changed at Amdt 7" tag on a slide.
- **Explanatory Note to ED Decision 2025/003/R** — rationale, scope and
  comment-response summary behind Amendment 8. Source for the "why it changed"
  narrative, not for normative text.

## Provenance rule

Do not substitute a mirrored or third-party copy. If a link 404s, resolve the
current file from the EASA landing page in the table above — EASA rotates the
numeric `/en/downloads/<id>/en` IDs when a document is republished.
